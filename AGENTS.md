# clay

Godot 4.7 claymation-style 3D game: an expressive rolling clay ball moves across a narrow grass-and-dirt diorama.

- Preserve the hand-sculpted, matte, imperfect look; visual charm is a product requirement.
- Godot 4.7, GDScript, GL Compatibility renderer, Jolt Physics. Open/run `project.godot`; no build, lint, or formatter is configured; `tools/deform_probe.tscn` is the one automated check.
- Terrain is generated by `scripts/terrain_generator.gd`; its mesh is intentionally not serialized. The player face is separate from the rolling body.
- Inspect relevant scenes/scripts before changing behavior. Keep changes focused; preserve working public behavior unless the task needs otherwise.
- Source is authoritative. Reuse the existing fingerprint-normal material approach for new clay assets when applicable.
